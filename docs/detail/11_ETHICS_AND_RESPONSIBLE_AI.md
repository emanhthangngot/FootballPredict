# 11. ETHICS AND RESPONSIBLE AI — Football Analytics

## 1. Positioning

This product is an analytics and educational platform. It must not encourage real-money betting.

## 2. Required Disclaimer

For Simulation Lab:

```text
This simulation is for educational and research purposes only.
It does not encourage or support real-money betting.
```

## 3. Responsible UX

Do:

```text
Show uncertainty
Show edgeReliable
Show stale odds warning
Show model-only view when market odds unavailable
Show historical performance and calibration
```

Do not:

```text
Guarantee outcomes
Use manipulative betting language
Hide stale data
Fake market edge for missing market type
Present simulation as actionable gambling advice
```

## 4. Bias and Limitations

Potential issues:

```text
League coverage bias
Data provider missing odds for smaller leagues
Market odds timestamp differences
Team-name normalization errors
Model drift by season
Low sample size for rare outcomes
```

## 5. Safety Controls

```text
Guided AI chat only
Prompt injection guard
Rate limiting
Admin-only simulation
No direct betting links
No real-money workflow
```
